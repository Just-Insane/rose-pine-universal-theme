# Fixture coverage and limits

`mixed.html` covers contrasting light and dark surfaces, a coloured badge, a more-specific background override, light- and dark-mode neutral text regressions, links, gradients, a warning colour, a pseudo-element overlay, disabled and interactive elements, a changing disabled state, hover, scrolling, and an in-place CSSOM update. `csp.cjs` exercises a strict style policy, and `bitwarden.cjs` checks the dark brand-button token in isolated Chromium and WebKit. Browser runs use a fresh context per appearance and a synthetic origin. The axe result is diagnostic: known intentionally skipped cases can remain, so the suite asserts the targeted behavior separately and prints the audit count.

Notte comparison: on a local synthetic page in an isolated Vivaldi profile with Notte 2.0.2's AA contrast tool enabled and dark mode disabled, the dark-panel link measured 2.86:1, a previously readable green badge measured 1.32:1, and overlay text measured 2.34:1. In its dark mode these synthetic samples measured above 6:1. An in-place badge stylesheet change was visible in the light case but was not observed in the dark case in that run. This is not an assessment of all sites or Notte configurations. No Notte code is bundled.
